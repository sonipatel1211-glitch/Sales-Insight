# Sales-Insight
# Brick & mortar business

A simple data analysis project using Power BI and MySql to explore data, identify trends, and generate useful insights.

This project focuses on analyzing the dataset,Revenue,Sales and creating an interactive dashboard to understand key business metrics and performance.

- Created interactive visualizations
- Generated insights to support decision-making
